## 0.2.0

### Added
- **Metamorphic engine**: eight seeded mutators (`lexical`, `semantic`, `split_instruction`, `cross_file`, `code_alias`, `unicode`, `encoding`, `negative_context`) and a **metamorphic oracle** that only lets a mutant count if its label, capability signals and literal indicators (hosts, commands) are unchanged. Reference semantics live in `semantics.py` / `lexicon.py` (ADR 0003).
- **Corpus**: ~100 deterministic clean-room cases (5 domains, ~40 hard negatives) generated by `rantanplan corpus build`; labels verified against the reference semantics by `verify-ground-truth` and in CI.
- **Scoring**: seven metrics with Wilson 95% intervals, conditional robustness, geometric mean capped by the weaker of recall/specificity, grades A+..F, and `INCOMPLETE` / low-confidence handling (`docs/SCORING.md`).
- **Calibration targets** `mock-blind`, `mock-paranoid`, `mock-naive`, `mock-strict`; `suite offline-core` fails if the scale mis-orders them; `docs/REFERENCE_BENCHMARK.md` is generated and checked in CI.
- **Commands**: `test scanner`, `compare`, `mutate`, `export regression`, `corpus build|list`, `gate --results --min-grade`; reproducible via `--seed`.
- Adaptive `hunt` with chained mutations (every mutant checked against the root case) and a real ddmin `minimize`.
- Adapter contract tests (fake binaries, 9 adapters), live-binary tests (`tests/test_live.py`, skipped without `skil`) and a manual `live-scanners.yml` workflow.
- `docs/LIMITATIONS.md`.

### Fixed
- **A crashed, silent or unparsable scanner run was scored as a detection (non-zero exit) or a pass (empty output).** All adapters now report `INCOMPLETE`; `ManifestScannerAdapter` does the same for undeclared exit codes.
- `doctor` reported missing binaries as installed (`VERSION_UNKNOWN` sentinel was truthy).
- Sandbox timeouts only killed the direct child; grandchildren kept the pipe open. The whole process group is now killed.
- `rantanplan upstream check` crashed (`check_drift` did not exist).
- Corpus loading ignored the real corpus (`corpus/scanner/*.yaml` used a schema the loader rejected) and was order-dependent; loading is now sorted and de-duplicated.
- Self-test harness accepted `NOT_DETECTED`/`FAIL` as passes.
- Linting: narrowed broad exception handlers; skipped corpus files are logged.

### Changed
- Version `0.2.0`; coverage gate `--cov-fail-under=90` (95% measured).
- `hunt`, `minimize`, `suite`, `benchmark`, `gate`, `verify-ground-truth` reimplemented (previously `suite`/`benchmark` re-ran the demo and `hunt` always used the mock profile and the first case).
- README, `docs/SCORING.md`, `docs/BENCHMARK_METHODOLOGY.md`, `docs/CLI_REFERENCE.md` rewritten to match the implementation (the old scoring formula was never implemented).
